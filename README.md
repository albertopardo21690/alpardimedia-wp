# Alpardimedia WP

SaaS para provisionar y gestionar instalaciones WordPress por usuario.

## Stack
- **Frontend:** Angular 17+ (standalone)
- **Backend:** Node.js + Express
- **BD:** MySQL
- **Provisioning:** wp-config.php dinámico + WP REST API
